    Capture a real SAML response from your own sign-in
    1. Open your browser’s developer tools, go to the Network tab, and turn on Preserve log.
    2. Sign in to any app that uses SAML SSO.
    3. Find the POST request to the app’s ACS URL, open Payload, and copy the SAMLResponse value. Browser add-ons like SAML-tracer do this too.
    4. Paste it above, fill in the app’s entity ID and ACS URL under Service provider settings, and run the checks.

    You can also paste an OIDC ID token, an IdP error like an AADSTS code, a SCIM error, or dig TXT output. A real SAML response includes your name and email, so use a test account or one you don’t mind sharing with Claude.
